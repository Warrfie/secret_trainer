## Версия без сервера

https://warrfie.github.io/secret_trainer/

Задание генерируется прямо в браузере
библиотекой [combidata-js](https://github.com/Warrfie/combidata-js), а вариант, сохранённые записи
и история запросов хранятся в localStorage. На стартовой странице выбираются практика и сложность
(лёгкий или сложный), позывной генерируется по кнопке «Получить задание»; начатые задания
можно продолжить из списка ниже. Практики:
- **Практика фронт** (`#/front/{позывной}`) — тестирование через интерфейс: форма карточки цели,
  кнопки «Исправить поле» и «Завершить тестирование», карточка того, что сохранилось;
- **Практика бэк** (`#/dock/{позывной}`) — тестирование API: эндпоинты `/send`, `/receive`, `/fix`, `/end`
  работают так же, как на сервере, запросы отправляются через консоль на странице задания
  (или из DevTools: `trainer.request("GET", "/end", {agent: "EZ675K"})`).

У каждой практики свой вариант, даже при одинаковом позывном.

При исправлении нужно указать не только поле, но и тип ошибки (в бэке — заголовок `type`,
коды перечислены в документации задания). Каждое неверное исправление — страйк, после трёх страйков
задание провалено. Типы багов заданы в `docs/js/libraries.js` (`BUG_TYPES` и `bugType` у каждого кейса).

### Локальный запуск
`python3 -m http.server 8765 --directory docs` и открыть http://localhost:8765/

## Серверная версия для тестирования только бэка

Чтобы запустить полноценный сервер локально, следуйте инструкции:

1) Скачать проект с GitHub https://github.com/Warrfie/secret_trainer
2) Все файлы проекта перенести в удобную папку, например C:\secret_trainer 
3) Загрузить и установить docker https://www.docker.com/
4) Для Windows потребуется установить WSL. Можно пойти по официальному пути через Microsoft Store, можно просто скачать по ссылке https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_x64.msi
5) Запустить docker 
6) Открыть терминал и перейти в папку проекта по команде cd C:\secret_trainer 
7) Выполнить команду docker compose -f docker.yaml up -d 
8) Поздравляю, сервер доступен по адресу http://localhost/

Для начала тестирования требуется придумать логин типа RR000R,
где R - любая заглавная латинская буква,
а 0 - любая цифра. 
Этот логин внести в ModHeader как заголовок agent (Пример agent : RR000R)
после установки заголовка, страницу перезагрузить
